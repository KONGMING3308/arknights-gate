## 五、保留不改的项（附理由）

| 项 | 理由 |
|---|---|
| 流星台词「某个狙击干员……记不清名字」未点名「守林人」 | 入侵者的表演性线索；她的破绽在照片，不依赖台词 |
| 担保失效时批准扣 15（而非入侵者的 25） | 规则上「手续无效」不等于「确认是入侵者」，惩罚略轻是有意设计；拒绝仍然恒正确，不影响判断方向 |
| 普瑞塞斯结算显示「判断正确」 | 数值上确实 ±0；若单独做「无法判定」文案属体验优化，非逻辑错误 |
| 3 位干员出身「未公开」、阿米娅特殊种族、杜宾伪造职业 | 分别为官方未公开、官方特殊设定、破绽设计 |
