# 02 · 功能清单

> 本文件列出「明日方舟 · 罗德岛入境审查」的全部功能项，含编号、名称、描述、优先级（P0–P2）与状态。
> P0 功能附验收标准指引，详细 Given/When/Then 见 [05-验收标准](./05-验收标准.md)。
> 状态诚实记录：已完成 / 进行中 / 未开始。判定依据为实际源码，而非计划。

---

## 一、优先级定义

| 优先级 | 含义 | 验收要求 |
|---|---|---|
| P0 | 核心可玩，M1 必须完成 | 必须有验收标准（见 05） |
| P1 | 重要，M2 完成 | 建议有验收标准 |
| P2 | 增强，后续迭代 | 可延后 |
