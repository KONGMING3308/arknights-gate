## 三、启动方式

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器（默认 http://127.0.0.1:5273，host 0.0.0.0 局域网可访问）
npm run dev

# 3. 类型检查
npm run typecheck

# 4. 生产构建
npm run build

# 5. 预览构建产物
npm run preview
```

> 端口为 **5273**（见 `vite.config.ts` 的 `server.port`），不是 Vite 默认的 5173。
> `server.watch.usePolling=true` 是为避免编辑器临时目录导致 EBUSY，正常使用不受影响。
> 生产构建 `base='/arknights-gate/'`（适配 GitHub Pages 子路径），本地开发仍用根路径。

## 四、VITE_USE_MOCK 切换步骤

数据访问层在 `src/api/client.ts`：

```ts
export const USE_MOCK = import.meta.env.VITE_USE_MOCK !== 'false'
```

即**未设置 `VITE_USE_MOCK` 时默认启用 Mock**，只有显式写 `VITE_USE_MOCK=false` 才走真实接口。

### 4.1 Mock 模式（默认）

无需任何配置，直接 `npm run dev` 即默认启用 Mock（仓库自带 `.env` 亦写 `VITE_USE_MOCK=true`，仅作显式声明）。`.env.example` 提供示例。

Mock 模式下：`fetchDayRoster` 按配额定向抽取（5 天 3/6/7/8/8 共 32 人 + 普瑞塞斯异常最多 33 人，顺序种子存 localStorage `arknights-gate-order`），`fetchPassport/fetchDossier` 走 `ALL_PASSPORTS/ALL_DOSSIERS`（82 人候选池 + 普瑞塞斯），`submitVerdict` 仅 sleep。

### 4.2 真实接口模式

编辑根目录 `.env`（或新建 `.env.local` 覆盖）：

```bash
VITE_USE_MOCK=false
VITE_API_BASE_URL=https://your-api-host
```

此时所有请求走 `request<T>(path)` = `fetch(`${API_BASE}${path}`)`，路径见 [04-数据模型](./04-数据模型.md) 接口表。
真实后端当前**未实现**，仅为预留。

> 环境变量文件说明：`.env` 为仓库默认（提交）；`.env.local` 为本地覆盖（不提交，优先级更高）；`.env.example` 为示例模板。

## 八、已知限制

| 限制 | 说明 |
|---|---|
| **DSH 模型通道不支持 images 端点** | DSH 的模型通道（bee/gpt/gemini 等）不直接提供 `images/generations` 能力。游戏素材通过 `scripts/gen_image.mjs` / `gen_image_edit.mjs` **直连中转站**（默认 `https://www.jiangeyun.xyz/v1`，需 `GPT_API_KEY`，模型 `gpt-image-2.6-flare`）生成，不走 DSH 模型通道。兜底可用 pollinations 免费接口（返回 JPEG）。 |
| **全部 5 天已开放，每日按配额随机抽取** | `ROSTER_SIZE={1:3,2:6,3:7,4:8,5:8}`（共 32 人），入侵者配额 1/1/2/2/2；申请人自 82 人候选池（池内 19 入侵者）定向随机抽取（先入侵者后补足再洗牌），顺序种子存 localStorage（`arknights-gate-order`），刷新不变、开新局重新随机；普瑞塞斯随机插入第 3–5 天（`arknights-gate-anomaly`）。自动通关验证：33 人全对、S 级。 |
| **射击系统已彻底移除** | `VerdictAction` 仅含 `approve \| reject`；`GunOverlay`、`AssaultScene`、`execute` 分支、枪声音效均已删除；`weapon.ts` 与 `weapons/` 素材仅作历史归档保留。突脸事件已改为 S.W.E.E.P. 求援（见 F-23 / AC-19）。 |
| **数值平衡待调** | 全对时总分约 288（含 S.W.E.E.P. 全部成功）远高于 S 线 190，评级区分度不足（当前沿用 S≥190/A≥170/B≥145/C≥110）。建议后续重校阈值或给数值加上限。 |
| **沙盒默认禁止创建子进程** | DSH 沙盒默认禁止创建子进程，`npm run dev` / `vite build` 等需要更宽的执行权限才能运行；本地开发需在具备执行权限的环境中启动。 |
| **文件监听 EBUSY 问题** | 编辑器落盘会产生临时目录（`.tmpdir` 等），Vite 原生 watcher 遇到会 EBUSY 崩溃；已在 `vite.config.ts` 改为轮询（`usePolling:true, interval:400`）并忽略临时目录与 node_modules/dist。 |
| **CodexScreen 未实现** | P2 图鉴页未做，路由未注册。 |
| **真实后端未实现** | 接口签名已预留，但无后端服务，切真实模式（`VITE_USE_MOCK=false`）会请求失败。 |
| **普瑞塞斯落点随局随机** | 落点存 localStorage（`arknights-gate-anomaly`），同一局内刷新不变；点「开始值班」开新局才重新随机；测试时需固定种子或临时硬编码。 |
