## 一、产品背景

《这不是我的干员》是一款基于明日方舟世界观的同人网页游戏，玩法致敬《请出示证件》（Papers, Please）、《边境检察官》与《这不是你的邻居》。

玩家扮演罗德岛人事部审查岗，每天面对若干申请入舰的干员或访客，其中混有不该进入本舰的入侵者。玩家需要比对「通行证 / 罗德岛人事档案 / 本人 / 对话」四类信息，找出印章、编号、姓名、照片、职业、档案状态、担保人、言行等 8 种维度的矛盾，然后作出处置：**批准**或**拒绝**。

> 注：v0.x 曾存在「拔枪射击」作为第三种处置手段；自 v1.0 起射击系统已彻底移除，仅保留「批准 / 拒绝」两种操作。相关历史代码与文案均已删除。

游戏共 5 天，从 82 人候选池（含 19 名入侵者）中按配额随机抽取 32 名申请人（D1:3 / D2:6 / D3:7 / D4:8 / D5:8），伪造手法逐日升级。玩家有两项数值：安全度（放走入侵者会下降）与信任度（误拒正常干员会下降），任一归零即被撤职失败；撑过 5 天则按两项残值之和给出通关评级。

- **题材来源**：明日方舟罗德岛世界观（同人，非官方）。
- **运行形态**：纯前端浏览器游戏，打开即玩，无需安装、无需后端（真实接口为预留，见 [04-数据模型](./04-数据模型.md) 接口表）。
- **内容形式**：82 人手工剧本候选池，每局按天定向抽取后洗牌；身份、伪造点、台词固定，出场顺序随种子变化；存档用 localStorage。

## 二、目标用户

| 用户画像 | 描述 |
|---|---|
| 核心玩家 | 明日方舟受众中喜欢「请出示证件」式审查玩法的玩家，对干员身份有认知，能从代号、出身、担保人等细节中获得代入感 |
| 次核心玩家 | 喜欢轻量推理 / 文字审查类小游戏、但未必熟悉明日方舟的玩家，靠游戏内提示也能玩 |
| 用户特征 | 非技术人员为主，习惯浏览器打开即玩，对复杂安装、账号注册有抵触；偏好短局（单局约 15–25 分钟） |

---

## 三、用户痛点

| 编号 | 痛点 | 说明 |
|---|---|---|
| P-1 | 同人审查类游戏稀缺 | 明日方舟题材缺少「请出示证件」式的沉浸式审查体验，现有同人多为卡牌或塔防 |
| P-2 | 重玩内容完全随机导致无法精进 | 部分审查游戏靠程序生成，玩家无法靠记忆与经验提升；本游戏用固定候选池 + 固定破绽设计，让玩家能逐步掌握每个伪造点 |
| P-3 | 处置判断缺乏深度 | 传统审查游戏往往只有「放行 / 拒绝」两极且线索单一；本游戏通过「备注自证」「言行不符」等进阶机制，要求玩家在破绽之外还要读备注、问话才能避免误判 |
| P-4 | 安装与上手门槛高 | 许多游戏需下载安装、注册账号；本游戏纯前端打开即玩，降低门槛 |
| P-5 | 难度无梯度 | 部分游戏破绽难度一刀切；本游戏按天递进伪造手法（D1 印章 → D2 编号 → D3 照片/职业 → D4 档案状态 → D5 多重破绽+言行），给玩家学习曲线 |

| US-02 | **作为一名**审查官玩家，**我想要**每天看到当天待审人员名单与我当前的安全度/信任度，**以便**随时掌握进度与风险。 | F-02、F-03 |

| US-04 | **作为一名**审查官玩家，**我想要**查看申请人提交的通行证（编号、姓名、照片、日期、路线、印章），**以便**核对基本信息。 | F-05 |

| US-11 | **作为一名**审查官玩家，**我想要**安全度或信任度归零时立即进入失败结局，**以便**清楚知道自己为何被撤职。 | F-13 |

## 五、非目标（明确不做的事）

| 项 | 说明 |
|---|---|
| 射击 / 拔枪处置 | v0.x 曾有，v1.0 已彻底移除；`VerdictAction` 现仅含 `approve \| reject` |
| 战斗场景 | 无战斗、无血条、无回合制；S.W.E.E.P. 仅为连点求援事件 |
| 后端服务 | 当前为纯前端 + Mock；真实接口仅预留签名，M2 不强制实现后端 |
| 程序生成内容 | 剧本手工固定（82 人候选池），不做运行时随机生成 |
| 多语言 | 仅中文 UI |
| 移动端原生 App | 仅浏览器，不做原生打包 |
| CodexScreen（图鉴） | HANDOFF.md 列为 P2，当前未实现，不在 M1/M2 必做范围 |
