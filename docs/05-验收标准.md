# 05 · 验收标准

> 本文档已按 v1.3 实际情况核对（2026-11-25），权威事实源见 12-当前状态.md

> 本文件为每个 P0 功能编写 Given / When / Then 验收条目。
> 游戏：**《这不是我的干员》v1.3**（原名《罗德岛入境审查》）。
> 数值依据 `src/constants/game.ts` 与 `src/utils/verdict.ts`；流程依据 `src/store/gameStore.ts` 与 `src/pages/Review/ReviewScreen.tsx`。
> 覆盖范围：进入审查、问三个问题、调取档案、批准/拒绝、备注自证与言行不符（进阶机制）、S.W.E.E.P. 求援事件、数值变化、天数推进、失败与结局、普瑞塞斯异常、变形者集群。
>
> 注：v1.0 起每日申请人按配额从候选池随机抽取（顺序种子本局固定），条目中出现的具体干员均为「被抽中时」的示例。

## AC-09 · 进阶机制① 备注自证（v1.0 新增）

> 防止「见破绽就拒」：编号不符但档案有「编号已换发」备注的正常干员，**应批准**。全剧本共 8 名（斯卡蒂、幽灵鲨、古米、空、暗索、深海色、星极、诗怀雅），每天约 2 名。

| 项 | 内容 |
|---|---|
| **Given** | 被抽中的「换发备注」干员：通行证号 ≠ 档案号，但档案备注（`Dossier.note`）注明编号已换发 |
| **When** | 调取档案并查看破绽提示（需先开启新手提示，`hintsEnabled=true`） |
| **Then** | 显示「已发现 1 处破绽（编号）」，hint 提醒阅读档案备注；按备注判定属正常换发，**应批准**：`computeOutcome('operator','approve')` 返回 `{safety:0, trust:+2, correct:true}` |

| 项 | 内容 |
|---|---|
| **Given** | 同上（备注自证干员） |
| **When** | 玩家仅因「编号不符」而点击「拒绝入境」 |
| **Then** | `computeOutcome('operator','reject')` 返回 `{safety:0, trust:-8, correct:false}`；信任 −8（误拒好人） |

## AC-12 · 失败结局（F-13）

| 项 | 内容 |
|---|---|
| **Given** | 某次处置后 `safety` 计算 ≤ 0（例如连续放走多个入侵者） |
| **When** | `applyVerdict` 中 `failed = safety<=0 \|\| trust<=0` 为 true |
| **Then** | `phase='ending'`（不再 advanceSlot），跳转 `/ending`，展示 `FAIL_TEXT.safety`「安全度归零。入侵者已经进入本舰，你被免职。」 |

| 项 | 内容 |
|---|---|
| **Given** | 某次处置后 `trust` 计算 ≤ 0（例如多次误拒正常干员） |
| **When** | `applyVerdict` 判定失败 |
| **Then** | `phase='ending'`，跳转 `/ending`，展示 `FAIL_TEXT.trust`「信任度归零。干员们不再信任审查官，你被调离岗位。」 |

| 项 | 内容 |
|---|---|
| **Given** | 数值用 `Math.max(0, …)` 兜底，不会变为负数 |
| **When** | 失败发生 |
| **Then** | safety 或 trust 显示为 0，结局文案对应归零项 |

## AC-13 · 通关评级（F-14）

| 项 | 内容 |
|---|---|
| **Given** | 第 5 天全部审完，数值未归零，`day=5` |
| **When** | DayEndScreen 点击「查看评级」 → `goNextDay()` 中 `day>=5` |
| **Then** | `phase='ending'`，跳转 `/ending`，展示通关分支：评级 + 最终安全度 + 最终信任度 + 「重新值班」按钮 |

| 项 | 内容 |
|---|---|
| **Given** | 通关时 `safety+trust = total` |
| **When** | `computeGrade(total, RATING_THRESHOLDS)` 计算 |
| **Then** | total≥190 → S；≥170 → A；≥145 → B；≥110 → C；<110 → D |

| 评级示例 | safety | trust | total | 评级 |
|---|---|---|---|---|
| 全对通关（33 人，S.W.E.E.P. 均成功） | 140 | 148 | 288 | S |
| 误拒 1 名正常干员 | 140 | 138 | 278 | S |
| 放走 1 名入侵者 | 115 | 148 | 263 | S |
| S.W.E.E.P. 失败 1 次 | 130 | 148 | 278 | S |
| 多次失误 | 60 | 45 | 105 | D |

> 全对基准推导：初始 100/100；拒绝 8 名入侵者安全 +40 → 140；批准 24 名正常干员信任 +48 → 148；普瑞塞斯不计分；合计 288。

## AC-14 · 天数推进（F-12 / F-15）

> `UNLOCKED_DAYS=5`，D1→D5 逐天推进；第 1–4 天结算后按钮为「进入下一天」，第 5 天为「查看评级」。

| 项 | 内容 |
|---|---|
| **Given** | day=1 全部审完，`UNLOCKED_DAYS=5`（已拍板放开全部 5 天） |
| **When** | 点击「进入下一天」 → `goNextDay()` |
| **Then** | 因 `day(1) < UNLOCKED_DAYS(5)`，进入 day=2、slotIndex=0、phase='review'；同理 D2→D3、D3→D4、D4→D5 逐天推进，不会提前进结局 |

| 项 | 内容 |
|---|---|
| **Given** | day=5 全部审完（最后一天） |
| **When** | 点击「查看评级」 → `goNextDay()` |
| **Then** | `day(5) >= UNLOCKED_DAYS(5)`，`phase='ending'`，进入通关结局（AC-13） |

## AC-16 · 进阶机制② 言行不符（v1.0 新增）

> 必须问话才能识破：证件完全正确的入侵者，唯一破绽是台词自称的担保人与证件不符（`Applicant.dialogueConflict`）。全剧本共 4 名，D1–D4 各 1 名。

| 项 | 内容 |
|---|---|
| **Given** | 被抽中的「言行不符」入侵者已加载，其通行证 / 档案 / 派遣函字段全部正确 |
| **When** | 仅核对材料、不问话，直接点击「批准入境」 |
| **Then** | `buildDiscrepancies` 返回 0 条材料破绽；`computeOutcome('impostor','approve')` 返回 `{safety:-25, trust:0, correct:false}`（放走入侵者） |

| 项 | 内容 |
|---|---|
| **Given** | 同上，玩家依次问完「代号」「来意」「担保人」 |
| **When** | 比对台词自称的担保人与证件担保人 |
| **Then** | 两者不符：崖心（证件「临光」/ 台词「银灰」）、送葬人（「塞雷娅」/「阿米娅」）、麦哲伦（「嘉维尔」/「凯尔希」）、白雪（「芙蓉」/「嘉维尔」）；此时**应拒绝**：`computeOutcome('impostor','reject')` 返回 `{safety:+5, trust:0, correct:true}` |

## AC-19 · S.W.E.E.P. 求援事件（F-23）

> 原 AC-19「拒后暴起射击（FPS）」已废弃，v1.0 移除；改为 S.W.E.E.P. 连点求援。
> v1.0 起触发随机化：**变形者集群拒绝时必定触发；其他入侵者按 `SWEEP.chance = 0.35` 随机触发**。
> 参数：`SWEEP = { taps: 10, duration: 9000, failSafety: 15, chance: 0.35 }`。

| 项 | 内容 |
|---|---|
| **Given** | 当前为变形者集群（`attacksWhenRejected=true`） |
| **When** | 玩家点击「拒绝入境」 |
| **Then** | **必定**触发：不直接结算，进入全屏 `SweepEvent`——多只黑色手剪影（红色轮廓光，`animate-reach` 循环）从各方向伸向屏幕；顶部 HUD 显示袭击者代号与进度条；底部「呼叫 S.W.E.E.P.」按钮可见 |

| 项 | 内容 |
|---|---|
| **Given** | 当前为其他入侵者（非变形者集群） |
| **When** | 玩家点击「拒绝入境」 |
| **Then** | 按 `SWEEP.chance=0.35` 随机触发 SweepEvent；未触发时直接按 reject 结算（安全 +5） |

| 项 | 内容 |
|---|---|
| **Given** | SweepEvent 进行中 |
| **When** | 玩家在 9 秒内连点「呼叫 S.W.E.E.P.」按钮达到 10 次 |
| **Then** | 触发成功结果：阿斯卡纶立绘（`ascalon.png`）登场，显示「非法入侵的变形者已被处决」+「S.W.E.E.P. 已控制现场。审查官，请继续值班。」；2.6s 后关闭事件，按 `reject` 结算（安全 +5，correct=true） |

| 项 | 内容 |
|---|---|
| **Given** | SweepEvent 进行中 |
| **When** | 9 秒超时仍未点够 10 次 |
