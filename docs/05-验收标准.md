# 05 · 验收标准

> 本文件为每个 P0 功能编写 Given / When / Then 验收条目。
> 数值依据 `src/constants/game.ts` 与 `src/utils/verdict.ts`；流程依据 `src/store/gameStore.ts` 与 `src/pages/Review/ReviewScreen.tsx`。
> 覆盖范围：进入审查、问三个问题、调取档案、批准/拒绝、S.W.E.E.P. 求援事件、数值变化、天数推进、失败与结局、普瑞塞斯异常、变形者集群。

## AC-08 · 批准 / 拒绝处置（F-09）

## AC-12 · 失败结局（F-13）

| 项 | 内容 |
|---|---|
| **Given** | 某次处置后 `safety` 计算 ≤ 0（例如连续放走多个入侵者） |
| **When** | `applyVerdict` 中 `failed = safety<=0 \|\| trust<=0` 为 true |
| **Then** | `phase='ending'`（不再 advanceSlot），跳转 `/ending`，展示 `FAIL_TEXT.safety`「安全度归零。入侵者已经进入本舰，你被免职。」 |

| 项 | 内容 |
|---|---|
| **Given** | 某次处置后 `trust` 计算 ≤ 0（例如多次误拒正常干员） |
| **When** | `applyVerdict` 判定失败 |
| **Then** | `phase='ending'`，跳转 `/ending`，展示 `FAIL_TEXT.trust`「信任度归零。干员们不再信任审查官，你被调离岗位。」 |

| 项 | 内容 |
|---|---|
| **Given** | 数值用 `Math.max(0, …)` 兜底，不会变为负数 |
| **When** | 失败发生 |
| **Then** | safety 或 trust 显示为 0，结局文案对应归零项 |

## AC-13 · 通关评级（F-14）

| 项 | 内容 |
|---|---|
| **Given** | 第 5 天全部审完，数值未归零，`day=5` |
| **When** | DayEndScreen 点击「查看评级」 → `goNextDay()` 中 `day>=5` |
| **Then** | `phase='ending'`，跳转 `/ending`，展示通关分支：评级 + 最终安全度 + 最终信任度 + 「重新值班」按钮 |

| 项 | 内容 |
|---|---|
| **Given** | 通关时 `safety+trust = total` |
| **When** | `computeGrade(total, RATING_THRESHOLDS)` 计算 |
| **Then** | total≥190 → S；≥170 → A；≥145 → B；≥110 → C；<110 → D |

| 评级示例 | safety | trust | total | 评级 |
|---|---|---|---|---|
| 全对通关（33 人） | 145 | 146 | 291 | S |
| 误拒 1 干员 | 145 | 138 | 283 | S |
| 放走 1 入侵者 | 120 | 146 | 266 | S |
| S.W.E.E.P. 失败 1 次 | 130 | 146 | 276 | S |
| 多次失误 | 60 | 45 | 105 | D |

## AC-14 · 天数推进（F-12 / F-15）

> `UNLOCKED_DAYS=5`，D1→D5 逐天推进；第 1–4 天结算后按钮为「进入下一天」，第 5 天为「查看评级」。

| 项 | 内容 |
|---|---|
| **Given** | day=1 全部审完，`UNLOCKED_DAYS=5`（已拍板放开全部 5 天） |
| **When** | 点击「进入下一天」 → `goNextDay()` |
| **Then** | 因 `day(1) < UNLOCKED_DAYS(5)`，进入 day=2、slotIndex=0、phase='review'；同理 D2→D3、D3→D4、D4→D5 逐天推进，不会提前进结局 |

| 项 | 内容 |
|---|---|
| **Given** | day=5 全部审完（最后一天） |
| **When** | 点击「查看评级」 → `goNextDay()` |
| **Then** | `day(5) >= UNLOCKED_DAYS(5)`，`phase='ending'`，进入通关结局（AC-13） |

## AC-19 · S.W.E.E.P. 求援事件（F-23）

> 替代原 AC-19「拒后暴起射击」。射击系统已移除，改为 S.W.E.E.P. 连点求援。

| 项 | 内容 |
|---|---|
| **Given** | D4 能天使（`attacksWhenRejected=true`） |
| **When** | 玩家点击「拒绝入境」 |
| **Then** | 不直接结算，进入全屏 `SweepEvent`：多只黑色手剪影（红色轮廓光，`animate-reach` 循环）从各方向伸向屏幕；顶部 HUD 显示袭击者代号与进度条；底部「呼叫 S.W.E.E.P.」按钮可见 |

| 项 | 内容 |
|---|---|
| **Given** | SweepEvent 进行中 |
| **When** | 玩家在 9 秒内连点「呼叫 S.W.E.E.P.」按钮达到 10 次 |
| **Then** | 触发成功结果：阿斯卡纶立绘（`ascalon.png`）登场，显示「非法入侵的变形者已被处决」+「S.W.E.E.P. 已控制现场。审查官，请继续值班。」；2.6s 后关闭事件，按 `reject` 结算（安全 +5，correct=true） |

| 项 | 内容 |
|---|---|
| **Given** | SweepEvent 进行中 |
| **When** | 9 秒超时仍未点够 10 次 |
| **Then** | 触发失败结果：闪红 +「增援未能及时抵达」+「你被拖进黑暗里——安全度下降。」；1.4s 后关闭事件，先 `penalize(-15, 0)` 扣安全度，再按 `reject` 结算（安全 +5，correct=true；净效果为安全 −10） |

| 项 | 内容 |
|---|---|
| **Given** | 当前为正常干员（operator），如克洛丝 |
| **When** | 玩家点击「拒绝入境」 |
| **Then** | 不触发 SweepEvent（仅 `attacksWhenRejected=true` 的入侵者才会触发），直接按 reject 结算 |

## AC-21 · 异常存在「普瑞塞斯」（F-25）

| 项 | 内容 |
|---|---|
| **Given** | 本局随机落点 `ANOMALY_DAY` ∈ {3,4,5}，`ANOMALY_SLOT` ∈ [0,3] |
| **When** | `fetchDayRoster(ANOMALY_DAY)` 执行 |
| **Then** | 返回名单中包含普瑞塞斯（`kind:'anomaly'`），插入到 `ANOMALY_SLOT` 位置，后续申请人 slot 重排；其他天数名单不含普瑞塞斯 |

| 项 | 内容 |
|---|---|
| **Given** | 普瑞塞斯已加载，展示其通行证与档案 |
| **When** | 检查证件字段 |
| **Then** | 所有字段均为「？？？？」乱码；通行证 `stampType:'missing'`；档案 `status:'missing'`；右栏 DossierPanel 显示「校验失败：该申请人的全部字段无法解析。」 |

| 项 | 内容 |
|---|---|
| **Given** | 普瑞塞斯已加载，三问按钮可用 |
| **When** | 玩家依次点击「代号」「来意」「推荐人」 |
| **Then** | 回答分别为「想我了吗？预言家」「你忘记我了吗？没关系」「我们该如何确定一颗星星是在接近还是远离我们？」 |

| 项 | 内容 |
|---|---|
| **Given** | 当前为普瑞塞斯（`kind:'anomaly'`），`safety=100`，`trust=100` |
| **When** | 玩家点击「批准入境」或「拒绝入境」 |
| **Then** | `computeOutcome('anomaly', action)` 返回 `{safety:0, trust:0, correct:true}`；数值不变；`lastOutcome.correct=true`；**不触发 S.W.E.E.P.**（即使点击拒绝） |
