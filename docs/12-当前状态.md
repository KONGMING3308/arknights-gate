## 三、玩法核心

玩家是罗德岛人事部审查岗，逐份审核入舰许可，决定**批准**或**拒绝**。

### 判断三步

1. **看材料** —— 通行证、人事档案、派遣函的编号 / 印章 / 照片 / 职业是否对得上
2. **读备注** —— 编号不一致时，先看档案有没有「换发记录」；有则属正常
3. **问话** —— 三个问题（代号 / 来意 / 担保人）都要问，比对他说的人和证件写的人

> 只看第 1 步会误拒好人（扣信任）；不问第 3 步会放走入侵者（扣安全）。

### 三个提问按钮（固定）

`代号` / `来意` / `担保人`

## 四、数值规则（`src/constants/game.ts`）

初始：安全度 100、信任度 100。任一归零即失败。

| 情形 | 安全度 | 信任度 | 判定 |
|---|---|---|---|
| 正常干员 · 批准 | 0 | **+2** | ✅ 正确 |
| 正常干员 · 拒绝 | 0 | **−8** | ❌ 判错 |
| 入侵者 · 批准 | **−25** | 0 | ❌ 判错 |
| 入侵者 · 拒绝 | **+5** | 0 | ✅ 正确 |
| 担保人不在册 · 批准 | **−15** | 0 | ❌ 判错 |
| 担保人不在册 · 拒绝 | **+5** | 0 | ✅ 正确 |
| 普瑞塞斯（异常）· 任意 | 0 | 0 | 不计分 |

> 担保失效规则**优先于**身份判定。

### 评级（安全度 + 信任度）

S ≥ 190 / A ≥ 170 / B ≥ 145 / C ≥ 110 / D < 110

## 六、破绽维度（`src/utils/compare.ts`，共 9 种）

| 维度 | 触发条件 |
|---|---|
| 印章 | 按**章面图案**判断，见下方「印章图鉴」 |
| 编号 | 通行证号 ≠ 档案号（**有换发备注时仍会显示破绽，但属正常**） |
| 姓名 | 通行证持有人姓名 ≠ 档案代号 |
| 照片 | `photoMatch: false`（通行证照片为干扰图） |
| 职业 | 申报职业 ≠ 档案职业 |
| 档案状态 | `missing`（查无此人）/ `revoked`（已注销） |
| 担保人 | 担保人不在 `REGISTERED_OPERATORS` 名录 |
| 言行 | `dialogueConflict` 有值（台词说的担保人与证件不符） |
| **日期** | `issueDate >= expiryDate`（签发日期不早于到期日期，日期本身自相矛盾） |

### 印章图鉴（v1.1 起改为看图核对）

印章从「一行文字」升级为**五张真实印章图**（`public/assets/seals/`），玩家需对照标准章辨认：

| `sealId` | 图 | 判定 | 说明 |
|---|---|---|---|
| `standard` | `seal_standard.png` | ✅ 正常 | 罗德岛人事部标准章，132 名申请者中 122 人持此章 |
| `wrong_dept` | `seal_wrong_dept.png` | ❌ 破绽 | 机构名写成「罗德岛后勤部」，其余与标准章一致（闪灵、艾丝黛尔） |
| `foreign` | `seal_foreign.png` | ❌ 破绽 | 整个章不属于罗德岛（水月、鞭刃） |
| `fake` | `seal_fake.png` | ❌ 破绽 | 机构名对，但边框 / 字距 / 中心纹样与标准章不同（崖心、赫拉格） |
| `smudged` | `seal_smudged.png` | ❌ 破绽 | 糊成一团，辨识不出机构（米格鲁、蓝毒） |
| `none` | 无图，显示「无入境章」 | ❌ 破绽 | 根本没有章（变形者集群、早露） |

> 其余 122 人全部 `standard`。旧数据的 `stampType` / `sealText` 由 `resolveSealId()` 兼容推断。
> 印章图均为 512×512 透明 PNG，`mix-blend-multiply` 压在纸张纹理上，与护照卡一体。

## 七、进阶机制（v1.0 起引入，v1.1 增补）

### ① 备注自证（防止「见破绽就拒」）

- **8 名正常干员**（每天 2 名）的通行证号与档案号不一致
- 但档案里有「编号已换发」备注（`Dossier.note`）
- 破绽提示会显示「已发现 1 处破绽（编号）」，hint 提醒去读备注
- **这类人应批准**——误拒扣信任

名单：斯卡蒂、幽灵鲨、古米、空、暗索、深海色、星极、诗怀雅

### ② 言行不符（必须问话才能识破）

- **4 名入侵者**（D1–D4 各 1 名）证件**完全正确**
- 唯一破绽是台词自称的担保人与证件不符（`Applicant.dialogueConflict`）
- 不问三个问题就批准 → 判错

| 入侵者 | 证件担保人 | 台词自称 |
|---|---|---|
| 崖心 | 临光 | 银灰 |
| 送葬人 | 塞雷娅 | 阿米娅 |
| 麦哲伦 | 嘉维尔 | 凯尔希 |
| 白雪 | 芙蓉 | 嘉维尔 |

### ③ 日期倒置（v1.1 新增，全游戏唯一一例）

- **艾雅法拉**（D3，入侵者）：通行证签发日期 `1097-04-12` **晚于**到期日期 `1096-04-11`
- 这是全池**唯一**的日期矛盾；她同时是入侵者，属于「不看日期就放走」的陷阱
- 其他 131 人的日期均正常（正常干员、以及其余入侵者都保持原样，**不要**再给任何人加这个破绽）
- 判断提示：`签发日期早于到期日期`；破绽提示为「签发 1097-04-12 / 到期 1096-04-11」

### 效果实测（`scripts/test_depth.mjs`）

| 策略 | 结果 |
|---|---|
| 见破绽就拒（旧必胜法） | 32/33，判错 1 次 |
| 先读备注再判断 | 33/33 全对 |

> v1.1 扩池后抽到的具体人选每局不同，但「每天 1 个陷阱」的结构不变；`play_random.mjs` 连续跑仍 33/33 满分。

## 八、突脸事件（S.W.E.E.P. 求援）

### 触发规则（v1.0 起随机化）

| 对象 | 触发条件 |
|---|---|
| **变形者集群** | 拒绝时**必定**触发（`attacksWhenRejected: true`） |
| 其他**入侵者** | 拒绝时按 `SWEEP.chance = 0.35` **随机**触发 |
| 正常干员 | 永不触发 |
| 普瑞塞斯（异常） | 永不触发 |

### 事件流程

1. 全屏暗场，多只黑色手剪影（红色轮廓光）循环伸向屏幕
2. 底部出现按钮「呼叫 S.W.E.E.P.」
3. 玩家需在 **9 秒内连点 10 次**
4. **成功**：阿斯卡纶立绘登场 + 「非法入侵的变形者已被处决」→ 按拒绝结算（安全 +5）
5. **失败**：额外扣安全 **15** → 仍按拒绝结算

参数：`SWEEP = { taps: 10, duration: 9000, failSafety: 15, chance: 0.35 }`

素材：`public/assets/events/reaching_hand.png`、`ascalon.png`

## 九、特殊角色

### 普瑞塞斯（`kind: 'anomaly'`）

- 随机落在第 3–5 天的任意位置
- 所有证件字段为「？？？？」乱码，档案状态「查无此人」
- 三个问题固定回答：
  - 代号 →「想我了吗，预言家？」
  - 来意 →「你忘记我了吗？没关系。」
  - 担保人 →「我们该如何确定，一颗星星是在接近，还是远离我们？」
- **批准或拒绝都不计分**，也不会触发突脸
- 右栏显示「校验失败：该申请人的材料无法按常规规则核对。」
- 立绘：`preseth_avatar.png`（由全身立绘裁切）+ 故障抖动动画

### 变形者集群（D5，入侵者）

- 种族 / 出身 / 职业均为「未知」
- 编号 `RI-0000-000`（全零假编号），与档案不一致
- 无入境章（`stampType: 'missing'`）
- 担保人「——」不在名录
- **拒绝时必定突脸**
